# My Bot Hosting (private starter)

لوحة أولية خاصة لإدارة بوتات Node.js/Discord.js. الواجهة تدعم تسجيل دخول بكلمة مرور، رفع ZIP، تشغيل/إيقاف العملية، وعرض stdout/stderr.

## مهم جداً
- هذا مشروع تجريبي خاص بك، وليس منصة متعددة المستخدمين.
- تشغيل كود ZIP يعني تنفيذ كود برمجي على الخادم. ارفع ملفاتك أنت فقط؛ لا تستضف ملفات مجهولة.
- ليس مناسباً لاستضافة عامة أو بيانات حساسة دون عزل حقيقي (Docker/VM)، حدود موارد، TLS، إدارة أسرار، ومراجعة أمنية.
- Render Free لا يضمن تشغيل عمليات البوت 24/7؛ قد ينام/يتوقف. الواجهة المجانية لا تعني استضافة بوتات دائمة مجاناً.
- ملفات البوتات المخزنة في `bot-data/` محلية، وقد تُفقد عند إعادة إنشاء بيئة الاستضافة ما لم تستخدم قرصاً دائماً/تخزيناً مناسباً.

## تشغيل محلياً
يتطلب Node.js 18+ و npm:
```bash
npm install
```
عيّن متغيرات البيئة:
```bash
PANEL_PASSWORD='استخدم-كلمة-مرور-طويلة-وفريدة-هنا'
SESSION_SECRET='ضع-قيمة-عشوائية-طويلة'
```
ثم:
```bash
npm start
```
افتح `http://localhost:3000`.

## تجهيز ZIP للبوت
يجب أن يحتوي ZIP على `package.json` و `index.js` في الجذر. داخل `package.json` يجب وجود:
```json
{"scripts":{"start":"node index.js"}}
```
إذا كان البوت يحتاج توكن، ضعه داخل إعدادات البيئة على الخادم، ولا تضعه في ZIP أو GitHub. هذا النموذج يمرر متغيرات بيئة الخادم إلى عمليات البوت؛ لا تستخدمه لاستضافة أشخاص آخرين.

## نشر تجريبي
ارفع الملفات إلى مستودع GitHub خاص، ثم اربطه بخدمة Node Web Service. Build: `npm install`; Start: `npm start`. أضف `PANEL_PASSWORD` و `SESSION_SECRET` في إعدادات البيئة. استخدم HTTPS. لا تنشر المستودع علنياً إذا احتوى أي أسرار.
